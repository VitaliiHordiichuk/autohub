AUTOHUB — BACKEND-АВТОРИЗАЦИЯ

Что добавляется:

POST /api/auth/register
POST /api/auth/login
POST /api/auth/logout
GET  /api/auth/me

Обычная регистрация всегда создаёт:

роль CLIENT
тип клиента REGISTERED
ценовую группу Registered со скидкой 5%
начальный профиль доставки PICKUP

Токен хранится в защищённой HTTP-only cookie.
Javascript в браузере не получает доступ к токену.

==================================================
1. РАСПАКОВКА
==================================================

cd ~/autohub-backend

unzip -o \
  ~/Downloads/autohub-auth-backend.zip \
  -d .

==================================================
2. БИБЛИОТЕКИ
==================================================

npm install bcryptjs jsonwebtoken cookie-parser

==================================================
3. СЕКРЕТ АВТОРИЗАЦИИ
==================================================

Выполнить один раз:

if ! grep -q '^AUTH_JWT_SECRET=' .env; then
  printf '\nAUTH_JWT_SECRET=%s\nAUTH_COOKIE_SECURE=false\n' \
    "$(openssl rand -hex 32)" >> .env
fi

Никому не передавать содержимое AUTH_JWT_SECRET.

==================================================
4. МИГРАЦИЯ
==================================================

psql -d autohub \
  -f migrations/023_add_customer_user_unique_index.sql

Ожидаемый конец:

COMMIT

==================================================
5. ЗАПУСК
==================================================

node src/server.js

==================================================
6. ПРОВЕРКА РЕГИСТРАЦИИ
==================================================

Открыть второй терминал:

curl -i \
  -c /tmp/autohub-cookies.txt \
  -H "Content-Type: application/json" \
  -d '{
    "firstName":"Тест",
    "lastName":"Клиент",
    "phone":"+380501112233",
    "email":"test-client@autohub.local",
    "password":"TestPass123"
  }' \
  http://localhost:4000/api/auth/register

Должно вернуть HTTP/1.1 201 Created.

==================================================
7. ПРОВЕРКА ТЕКУЩЕГО ПОЛЬЗОВАТЕЛЯ
==================================================

curl -i \
  -b /tmp/autohub-cookies.txt \
  http://localhost:4000/api/auth/me

Должно вернуть пользователя, роль CLIENT,
клиента REGISTERED и скидку 5%.
